## Getting help

Support is through GitHub issues only:
**[github.com/frankbria/code-evolve/issues](https://github.com/frankbria/code-evolve/issues)**.

- Search the open and closed issues first; your question may already have an answer.
- To report a bug, open a new issue with the code-evolve version (`npx code-evolve --version`), the
  agent you use (Claude Code, Codex, OpenCode, Ollama or a custom command), your operating system, and
  the command or skill you ran with its output. Remove API keys, tokens and private code before you
  post: issues are public.
- To ask for a feature, open an issue that describes what you want to do and why.

There is no email or phone support and no paid support plan.
